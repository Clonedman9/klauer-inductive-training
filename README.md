# 比较之间 · 克劳尔归纳训练

独立的单文件 HTML 训练网页，依据 Karl Josef Klauer 与 Gary D. Phye 公开论文中的归纳训练结构编写。

- 10 堂课，每课 12 道新题，共 120 题。
- 六类认知操作各 20 题；语言、图形、数量材料各 40 题。
- 包含逐级提示、答案讲解、分类复盘、三问记录和进度导入／导出。
- 无外部运行时依赖，可保存 HTML 后离线使用。
- 训练进度保存在使用者自己的浏览器中。

## 研究依据与范围

主要依据：Klauer, K. J., & Phye, G. D. (2008). *Inductive Reasoning: A Training Approach*. Review of Educational Research, 78(1), 85–123. https://doi.org/10.3102/0034654307313402

120 道题均为本项目新编；具体题序、每课题型配额和交互机制为本项目设计。未逐题核实作者原版题册，不属于官方软件或原版题库的复刻，亦未接受独立训练效果验证。详细文献及版本区别见网页「依据与说明」。

## 使用与部署

用浏览器直接打开 `index.html` 即可。GitHub Pages 从 `main` 分支根目录发布，无需构建。修改网页并提交到 `main` 后即可更新站点。
