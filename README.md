# 比较之间 · 克劳尔方法重做版 v2

在线使用：https://clonedman9.github.io/klauer-inductive-training/

依据 Karl Josef Klauer 与 Gary D. Phye 的公开理论及样题机制构造的原创浏览器训练。当前版本重做了题目要求和学习流程：学习者先发现规律并提交解答，随后进行反向查验，最后才显示解释。

## 题库与实际操作

- 10 堂课，每课 12 道主题，共 120 道主题；六类各20题，文字、图形、数量资料各40题。
- 概括／辨别：从可见材料中发现共同点或异项，不在题干直接给奇偶性、某个颜色组合等答案规则。
- 交叉分类：20题均为无分类标题的参照组，学习者发现两个分类维度后归位新对象；新对象还改变无关特点，避免按完全相同图片匹配。
- 关系识别：从续列或类比中发现并运用统一变换。
- 关系区分：20题均需要定位并选择替换对象，实际修复后前后关系都成立。
- 系统建构：缺项同时满足横向、纵向关系；检查环节换材料并从起点逆向还原。
- 每道主题附独立查验任务，不另计为主题。首答先保存，查验前不显示标准解法；发生错误后可读解释再修订，第一次记录保持不变。
- 三问可写可口述，不按字数或题型名称判定理解。自动判断限于结构化解答，无法代替训练者评估自由解释。
- 提示和逐项比较按需展开；最高级提示会给出规则，并被记录为有支持作答。

## 证据与范围

主要依据：Klauer, K. J., & Phye, G. D. (2008). *Inductive Reasoning: A Training Approach*. Review of Educational Research, 78(1), 85–123. https://doi.org/10.3102/0034654307313402

- pp.87–88：定义与六类操作，表1。
- pp.89–90、图3：整体观察、提出假设、定向比较验证；困难时转向逐项分析。
- p.91：版本与配额；不必先准确说出类别名称，能选用合适策略即可。
- pp.92–93：十课教学目标、三问与相反比较。
- Klauer, Willmes, & Phye (2002), 附录pp.21–23：https://gwern.net/doc/dual-n-back/2002-klauer.pdf#page=21 。六类原始样题，关系区分明确要求修复，交叉分类不预先标出类别。该样题来自1994年儿童版，用来核查机制，不代表取得了II／III完整题库。

120道主题均为本项目按操作模型构造的新实例，非原商业题册逐题复制。每课配额、具体模板、难度层次、检查题和交互为本项目选择。答案唯一性限于本项目可见属性／有限变换模型，不能排除所有人为数学规则。未进行独立教育效果评估，不承诺复现原研究效应。详见 [DESIGN.md](DESIGN.md) 和网页「依据与设计」。

## 离线使用与进度

用浏览器直接打开 `index.html`，或在网页点击「保存离线网页」。无外部图片、字体、脚本或评分接口。进度保存在使用者自己的浏览器，支持JSON导出／导入。v2采用独立存储，保留旧版数据但不混算不同任务的结果。

## 构建、验证与发布

```sh
node tests/engine.test.js
python3 build.py
```

已有 agent-browser 环境可执行完整浏览器流程（使用独立测试会话，不使用真实训练数据）：

```sh
agent-browser --session klauer-method-v2 open file:///absolute/path/index.html
agent-browser --session klauer-method-v2 eval --stdin < tests/browser-flow.js
agent-browser --session klauer-method-v2 close
```

结构验证覆盖120题及860项断言：六类配额、材料配额、可见维度内分类唯一性、无分类标题、修复结果和双向关系。另已在Chromium中逐题完成120次解答、120次反向查验和十课归类复盘，并检查390px手机布局、首次记录保持和备份往返。上述是软件与任务结构验证，不是教育效果实验。

GitHub Pages 从 `main` 分支根目录发布。修改 `src/` 后运行 `python3 build.py`，提交生成的 `index.html` 并推送 `main`。
